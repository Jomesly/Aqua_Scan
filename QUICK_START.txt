🎯 WHAT YOU NEED TO DO
══════════════════════

1. HARDWARE SETUP (10 minutes)
   □ Connect DS18B20 to Arduino GPIO 4
   □ Add 4.7kΩ pull-up resistor between VCC and DATA
   □ Optional: Connect 16x2 I2C LCD for local display
   □ Plug Arduino into USB

2. ARDUINO SETUP (5 minutes)
   □ Open Arduino IDE
   □ Install libraries: OneWire, DallasTemperature, LiquidCrystal_I2C, ArduinoJson
   □ Open arduino_temp_sensor.ino
   □ Upload to Arduino
   □ Note your COM port (Windows) or /dev/ttyUSB0 (Linux)

3. PYTHON SETUP (2 minutes)
   □ Install pyserial: pip install pyserial
   □ OR: pip install -r arduino_requirements.txt

4. START THE SYSTEM (1 minute)

   OPTION A - Windows (Easiest):
   □ Edit start_arduino_dashboard.bat
   □ Change COM3 to your Arduino port
   □ Double-click start_arduino_dashboard.bat

   OPTION B - Linux/Mac:
   □ Edit start_arduino_dashboard.sh
   □ Change /dev/ttyUSB0 to your Arduino port
   □ Run: ./start_arduino_dashboard.sh

   OPTION C - Manual:
   □ Edit Aqua_Scan/tilapiers/start_with_arduino.py
   □ Set ARDUINO_PORT = 'COM3'  (your port)
   □ Run: python start_with_arduino.py

5. VERIFY IT'S WORKING
   □ Dashboard opens at http://127.0.0.1:8000
   □ Go to "Environmental Parameters" section
   □ Temperature updates every 2 seconds
   □ NO "Simulated" badge appears (means Arduino connected!)
   □ Arduino LCD shows temperature


📊 HOW IT WORKS
════════════════

  Arduino DS18B20 Sensor (GPIO 4)
           ↓
  Reads temperature every 2 seconds
           ↓
  Sends JSON via Serial (115200 baud)
  {"status":"ok","temperature_c":27.5}
           ↓

           ↓
  arduino_integration.py
           ↓

           ↓

           ↓
  API: /api/environment
           ↓

  Environmental Parameters Section

🐛 QUICK TROUBLESHOOTING
═════════════════════════

Problem: "Could not connect to Arduino"
  → Check USB cable is plugged in
  → Verify correct COM port in Device Manager (Windows) or ls /dev/tty* (Linux)
  → Close Arduino IDE Serial Monitor if open

Problem: Dashboard shows "Simulated" badge
  → Arduino not connected properly
  → Check console for error messages
  → Test standalone: python arduino_serial_bridge.py COM3

Problem: "Sensor Error" on LCD
  → Check DS18B20 wiring to GPIO 4
  → Verify 4.7kΩ pull-up resistor between VCC and DATA
  → Test sensor with simple Arduino sketch

Problem: Permission denied (Linux)
  → Run: sudo chmod 666 /dev/ttyUSB0
  → Or: sudo usermod -a -G dialout $USER (then log out/in)
